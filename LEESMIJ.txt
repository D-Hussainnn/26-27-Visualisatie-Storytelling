PERSOON 2 – PYTHONOPDRACHT (OPDRACHT D, E EN F)

Deze map bevat alleen het werk van Persoon 2.

Bestanden:
- persoon2_opdracht.ipynb: notebook met grafieken D, E en F
- forest_area_cleaned.csv: bosgebiedgegevens voor grafiek D
- temperature_data.py: haalt temperatuurgegevens op van NASA en KNMI
- requirements.txt: benodigde Python-pakketten

Starten:
1. Pak de ZIP uit.
2. Open CMD in deze uitgepakte map.
3. Installeer de pakketten met: python -m pip install -r requirements.txt
4. Start Jupyter met: python -m jupyter notebook
5. Open persoon2_opdracht.ipynb en kies Run All.

Voor grafieken E en F is internet nodig, omdat de notebook echte gegevens ophaalt bij NASA en KNMI.
Grafiek F gebruikt meetgegevens van KNMI-station De Bilt (1995–2019), niet een landelijk gemiddelde.
